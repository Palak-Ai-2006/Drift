## Leakage checklist (PLAN.md Section 8)

- [ ] Split by case, never by row.
- [ ] No end-of-case totals used as features.
- [ ] Baseline/drift features use only data before the prediction time.
- [ ] Scaling, calibration, threshold chosen on train/validation only.
- [ ] Test set evaluated once; no tuning afterward.
- [ ] Causality unit tests pass.
- [ ] Event counts / positive rate printed for train/val/test.
- [ ] Bootstrap CIs by case.
- [ ] Confounders (anesthetic depth, vasopressors, surgical events) acknowledged.

## What this is not

Not clinically validated. Not a device. A research prototype trained on surgical
(intraoperative) data — not prehospital trauma. See [LIMITATIONS.md](LIMITATIONS.md).
